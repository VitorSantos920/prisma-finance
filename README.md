# Prisma Finance

Dashboard financeira pessoal para lanchonete familiar.

## Stack

- **Frontend:** React + TypeScript + TailwindCSS
- **Backend:** Node.js + Fastify + TypeScript + Prisma + PostgreSQL
- **Database:** PostgreSQL

## Estrutura

```text
prisma-finance/
  apps/
    web/    → frontend
    api/    → backend
  packages/
    shared-types/   → tipos compartilhados
```
